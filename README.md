# Neon Bay

Game 3D open-world orisinal di kota pantai neon. Rin, kurir lepas, mengambil tiga job dari fixer Mara Voss.

## Cara main

Buka `game/index.html` di browser desktop modern. Seluruh Three.js disimpan lokal di `game/vendor/`; game tidak memerlukan layanan jaringan.

WASD gerak/kemudi · Mouse orbit kamera · E masuk/keluar mobil · Space handbrake · F pukul · Shift boost (mobil) · R ulang misi · P pause · M mute.

Mode screenshot tersedia lewat query `?shot=start&seed=1`, `?shot=drive&seed=1`, `?shot=chase&seed=1`, dan `?shot=mission&seed=1`. Kit check: `MAKEFUN_OUTPUT_DIR=out node main.ts`.
